# student-registration-system

This is a Next.js project for a Student Registration System.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Or:

```bash
yarn dev
```

Or:

```bash
pnpm dev
```

Or:

```bash
bun dev
```

Open http://localhost:3000 with your browser to see the result.

## Project

This project is built with:

* Next.js
* React
* TypeScript
* Tailwind CSS
* Prisma
* MySQL
